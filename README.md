# ASTRA

ASTRA is an offline-first, community-led digital learning platform designed for rural and tribal students.

The platform helps students continue learning despite poor internet connectivity by providing:

- Offline learning resources
- Regional-language support
- Local AI doubt resolution
- Voice-based interaction
- Scholarship discovery
- Verified mentor guidance
- Career pathway support
- Learning progress and next-step recommendations

This frontend prototype is built using HTML, CSS and JavaScript with a clean white, beige, navy, teal and terracotta visual design system.

## Project Vision

ASTRA keeps learning moving when connectivity stops.
